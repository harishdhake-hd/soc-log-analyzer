# SOC Log Analyzer

A Python-based Security Operations Center (SOC) Log Analyzer designed to parse log files and identify potential security events. This project helps demonstrate log analysis and basic threat detection techniques used in cybersecurity operations.

## Features

* Read and analyze log files
* Detect suspicious activities
* Count security events
* Generate summary statistics
* Beginner-friendly implementation

## Technologies Used

* Python 3
* File Handling
* Log Analysis

## Project Structure

```
log-analyzer.py
sample.log
README.md
```

## How It Works

The program reads log entries from a log file, processes each line, and searches for indicators of suspicious or noteworthy events. It then produces a summary of findings.

## Usage

Run the analyzer:

```bash
python3 log-analyzer.py
```

Ensure that the log file is available in the project directory.

## Example Output

```
SOC Log Analysis Report

Failed Login Attempts: 15
Successful Logins: 8
Suspicious Events: 3

Analysis Complete.
```
